FitResult
##################

モデルのFit結果を格納するためのクラスです。

下記のクラスのFit()メソッドの返り値として利用されます。

* :doc:`../Models/Sequential`

クラス定義
*****************

ユーザはインスタンスしない想定なので省略します。

import記述例
*****************

.. code:: python

    from samact import FitResult

※アノテーションに利用する可能性を考慮して記載しました。

クラス要素
*****************

Parameters
========================

ユーザはインスタンスしない想定なので省略します。

Attributes
=====================

    metrics : list[float]
        学習epochごとの評価指標のリストです。
        :doc:`../Models/Sequential` のFit()のパラメータmetricsで指定した形式で返します。

        デフォルトの場合、正解率(accuracy)を返します。
